# Imprint

## Register

product

## Project

CJK Fontbook is a pan-CJK open-source font catalog site for discovering, filtering, previewing, and comparing Chinese, Japanese, and Korean fonts.

## Surface

Product surface. This is a font discovery tool, not a marketing site.

## Audience

Designers and developers looking for CJK fonts. They need to inspect language coverage, glyph flavor, categories, licenses, and preview text quickly enough to choose fonts for real projects.

## Brand

Clean, minimal, typography-focused. Fonts are the design; the interface should stay quiet and let specimens carry the visual interest.

## Current System

Astro, DaisyUI 5.x, Tailwind CSS 3.x, Preact, and PostgreSQL. The current design uses DaisyUI winter as the primary theme, a table-based font list, filters, and expandable previews.

## Strategic Principles

Make font specimens the primary visual signal.

Support expert scanning over decorative storytelling.

Use familiar product affordances for search, filters, tables, previews, and comparisons.

Respect Traditional Chinese UI text and CJK typography with enough spacing, line height, and responsive room.

Preserve the restrained DaisyUI-based identity unless a task explicitly calls for a redesign.

## Anti-references

Do not turn the catalog into a marketing landing page.

Do not use decorative visuals, heavy gradients, glass effects, loud color fields, novelty controls, or oversized promotional sections that compete with font previews.

Do not make the product feel like a generic SaaS analytics dashboard.
