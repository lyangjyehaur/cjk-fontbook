# Product

## Register

product

## Users

Designers and developers looking for open-source Chinese, Japanese, and Korean fonts for real projects. They arrive with practical questions: which fonts cover the script and regional glyph forms they need, how the type looks with their own text, what license applies, and which options are worth comparing side by side.

## Product Purpose

CJK Fontbook is a pan-CJK open-source font catalog for discovery, filtering, previewing, and comparison. It exists to reduce the time it takes to find usable CJK fonts without turning the catalog into a download host or marketing page. Success means users can confidently narrow a broad font set into a short, inspectable list.

## Brand Personality

Clean, minimal, typography-focused.

The interface should feel precise, calm, and useful. Fonts are the design; the UI frames the specimens and metadata without competing for attention. The voice should be professional, approachable, and direct, with Traditional Chinese as the primary interface language.

## Anti-references

Avoid marketing-site patterns: oversized hero sections, decorative illustration, sales copy, feature-card grids, and promotional statistics.

Avoid visual systems that compete with font previews: heavy gradients, ornamental backgrounds, loud color fields, glass effects, excessive shadows, or novelty controls.

Avoid generic SaaS dashboards that make the catalog feel like analytics software rather than a typography tool.

## Design Principles

Make font specimens the primary visual signal. Layout, color, and chrome should defer to the typefaces being inspected.

Support expert scanning. Designers and developers should be able to compare language coverage, category, license, and preview text without hunting through decorative UI.

Keep interactions familiar. Search, filters, tables, expandable previews, and comparison tools should use standard affordances with consistent states.

Respect CJK reading and typography. Traditional Chinese interface text and CJK preview content need enough line height, spacing, and responsive room to stay legible.

Preserve restrained identity. Use the DaisyUI winter-based product system and existing typography-first palette unless a task explicitly calls for a redesign.

## Accessibility & Inclusion

Target WCAG 2.1 AA for text contrast, keyboard operation, visible focus states, and form controls. Avoid color-only status communication. Keep motion minimal and respect reduced-motion preferences. Ensure previews and controls remain usable for users inspecting dense CJK text, including at smaller screen sizes.
